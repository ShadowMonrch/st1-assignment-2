# AI Reflection

Before using AI, I built a simple SmartCare appointment prototype using Python. I used a list and dictionaries to store patient names, practitioner names and appointment times, and created functions to book and display appointments. I also added validation to prevent an empty patient name and later added one controlled improvement to validate the practitioner name.

AI helped me understand how the booking function works and identified limitations such as the need for the appointments list to already exist, limited input validation and the lack of feedback from the function. AI also suggested improvements such as input validation and duplicate appointment checking.

The AI-generated version made an assumption that an appointments list already existed and did not include validation. I did not automatically accept the AI output. I verified its suggestions by reading the code, running the program and testing normal and unusual inputs, including blank and None values and duplicate appointments.

The engineering work that remained for me was deciding which suggestions were appropriate, testing the behaviour and making the final controlled improvement. This showed me that AI can help explain and suggest ideas, but I still need to understand, evaluate and verify the code myself.
